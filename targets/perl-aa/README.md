# Perl 5.44 /aa

See [`target.toml`](target.toml) for how irx drives this engine; run it with `tools/irx_target.py perl-aa`.
The [`perl`](../perl) driver with `/aa`: ASCII classes, and no case-insensitive match between ASCII and non-ASCII characters (`k` no longer matches the Kelvin sign; dialect `perl-aa`). Bugs found here are listed in the [bug ledger](../../README.md#bug-ledger).
